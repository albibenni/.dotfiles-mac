# Wallpapers

Add one wallpaper for each configured theme:

- `latte.webp`
- `frappe.webp`
- `macchiato.webp`
- `mocha.webp`
- `tokyonight.webp`
- `night-owl.webp`
- `custom.png` (your current desktop image)

`custom.png` is a copy of the desktop image that was active when this profile was created.
