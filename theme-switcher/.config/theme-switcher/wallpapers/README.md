# Wallpapers

Add one wallpaper for each configured theme:

- `latte.jpg`
- `frappe.jpg`
- `macchiato.jpg`
- `mocha.jpg`
- `tokyonight.jpg`
- `night-owl.jpg`

The switcher deliberately keeps the images out of Git. It will apply a wallpaper when the corresponding file exists and otherwise leave the current wallpaper unchanged.
